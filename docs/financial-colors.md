# Financial colors

Income uses a fixed emerald green (`--income`); spending uses a fixed red
(`--expense`). These semantic colors stay the same across all nine brand
palettes. Their light and dark variants preserve readable contrast against
every theme's paper and card surfaces. Soft companions provide tinted tiles.

Transaction amounts, scheduled payments, cash-flow charts, financial comparisons,
and income/outflow calendar marks use these tokens. Theme controls, buttons,
focus rings, account identities, and user category colors keep their own palette.
Neutral corrections and zero values retain their existing neutral treatment.

Validation covers actual transaction rows, report SVG series, the transaction
kind switch, and 16 representative CSS marks in all theme/appearance combinations.
Financial text meets a 4.5:1 contrast ratio against every theme's paper and card
background. The checks use offline fixtures and do not need production data.
